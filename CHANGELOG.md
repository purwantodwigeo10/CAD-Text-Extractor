# Changelog

## 0.26.01

- Export source geometries and selected attributes as CAD-compatible DXF entities.
- Assign compact polygon text heights automatically according to feature area.
- Arrange multiple text values vertically around the selected anchor point.
- Support centroid, inside-point, line-midpoint, and original-point placement.
- Use Middle Center alignment for exported text.
- Display live export progress from 0 to 100 percent.
