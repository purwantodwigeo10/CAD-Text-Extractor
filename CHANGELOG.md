# Changelog

All notable changes to CAD Text Extractor are documented here.

## 26.1.0 - 2026-09-13

- Improved AutoCAD R12 DXF export for point, line, polygon, multipart, and
  supported collection geometry.
- Preserved selected attribute values as CAD text on separate layers.
- Added unique R12-compatible layer names, sample data, and privacy disclosure.
- Improved output validation and removed duplicate DXF-writer code.

## 0.26.01

- Repaired malformed DXF line separators.
- Restored source geometry and attribute text export.
